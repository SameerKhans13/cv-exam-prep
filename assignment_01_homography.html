What the assignment asks

Understand the task before touching the code.

You receive pairs of images showing the same real-world scene from different viewpoints or lighting. For every pair, predict the homography H that maps coordinates in Image 1 to Image 2.

[u, v, w]ᵀ = H[x, y, 1]ᵀ
x′ = u / w    y′ = v / w
Goal

Submit one valid 3 × 3 transform per test pair, with h₃₃ fixed to 1.

Metric

Mean geometric reprojection error on five normalized reference points. Lower raw error is better.

Why it matters

Panorama stitching, AR tracking, document rectification and visual SLAM.

Submission

pair_id,h11,h12,h13,h21,h22,h23,h31,h32; h₃₃ is assumed to be 1.

The winning pipeline

Memorize this five-step answer for a design question.

①DetectSIFT keypoints + 128-d descriptors
②MatchBFMatcher with L2 distance
③FilterLowe ratio τ = 0.75
④FitRANSAC / USAC_MAGSAC
⑤ValidateNormalize h₃₃ and check inliers
Fallback: if fewer than four reliable inliers remain, return the identity matrix rather than NaN or an invalid transform.

Geometry you must know

Small formulas, guaranteed marks.

8 degrees of freedom

A 3 × 3 matrix has 9 entries, but scale is arbitrary. Set h₃₃ = 1, leaving 8 independent values.

Minimum data

Each point correspondence gives 2 equations. Four non-collinear pairs give 8 equations, enough for H.

DLT

Build A h = 0 from the correspondences, then take the right singular vector associated with the smallest singular value.

Projective divide

Always divide by w after applying H. Forgetting this produces incorrect pixel coordinates.

H ← H / H[2, 2]    (enforce h₃₃ = 1)
N = ⌈ ln(1 − p) / ln(1 − (1 − e)ˢ) ⌉    (RANSAC)

Q1 · Evaluation4 marks

Why use geometric reprojection error over five normalized points instead of comparing matrix entries element by element?

  1. Homographies are defined up to scale, so H and λH can represent the same transform.
  2. Matrix entries have unequal geometric effects; small changes in the bottom row can create large perspective distortions.
  3. Warping representative points measures the physical image-alignment error directly.
