Must-memorize formulas

Conv output = ⌊(W − K + 2P) / S⌋ + 1
Params = (K²Cin + 1)Cout
RANSAC N = ⌈ln(1−p) / ln(1−(1−e)^s)⌉
Homography: s = 4; p=.99,e=.5 → N=72
IoU = TP / (TP + FP + FN)
Dice = 2TP / (2TP + FP + FN) = 2IoU/(1+IoU)
Z = fB/d
ΔZ ≈ (Z²/(fB))Δd
R-precision = correct in first R / R
Sfusion = .6 Pclassifier + .4 cosineCLIP

Guaranteed exam traps to check

Harris: adding a constant to every pixel does not change derivatives or R.
Lowe: reject when d₁/d₂ ≥ τ; a ratio near 1 is ambiguous.
NMS: higher IoU threshold means fewer suppressions and more boxes survive.
Focal Loss: γ=0 becomes α-balanced cross-entropy.
Dropout: inverted dropout is identity in evaluation mode.
DETR: learned queries + Hungarian matching means no greedy NMS.
Dice: Dice ≥ IoU; IoU=.5 gives Dice=.667.
Coordinates: continuous boxes use (x₂−x₁)(y₂−y₁), no +1.
BN: training uses batch statistics; evaluation uses running statistics.
Video: GroupKFold by group_id prevents paired-clip leakage.

Answer frameworks

Question typeWrite these points
Compare detectorsArchitecture → anchors → duplicate removal → speed/accuracy → background handling.
Why DETR no NMS?Fixed learned queries → one-to-one Hungarian matching → duplicate queries penalized as ∅ → set prediction at inference.
Why hybrid retrieval?Classifier gives fine-grained category precision; CLIP handles synonyms and descriptive text; fusion is complementary.
Why GroupKFold?Paired clips share source video and group_id; random split leaks scene/camera cues; grouped split keeps source groups together.
Why reprojection error?H is scale-equivalent; matrix entries have unequal geometric effects; warped points measure actual alignment.

Rapid self-test

Answer aloud, then reveal the expected answer.

1. Four homography correspondences give how many DLT equations?

8. Each correspondence contributes two equations.

2. What happens to NMS when the threshold rises from .5 to .7?

Fewer boxes are suppressed; more survive. The threshold is more lenient.

3. R=20 and 14 correct in top 20: R-precision?

0.70. 14 / 20.

4. Why can random video splitting give a false validation score?

Paired clips from the same source leak camera, road and scene cues. Split by group_id.

5. At IoU=.5, what is Dice?

0.667. 2(.5)/(1+.5).

6. What is the CNN output for W=224,K=3,P=1,S=2?

112. floor((224−3+2)/2)+1.

7. Why does RoIAlign beat RoIPool?

It avoids coordinate rounding and uses bilinear interpolation.

8. What does w>1 do in classifier-free guidance?

Raises prompt fidelity while trading away diversity.
