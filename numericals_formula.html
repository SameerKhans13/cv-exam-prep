from math import ceil, log

def conv(w, k, cin, cout, s=1, p=0, d=1):
    keff = d * (k - 1) + 1
    out = (w - keff + 2 * p) // s + 1
    params = (k * k * cin + 1) * cout
    return out, params

def ransac(p, e, sample):
    return ceil(log(1 - p) / log(1 - (1 - e) ** sample))

def iou(a, b):
    x = max(0, min(a[2], b[2]) - max(a[0], b[0]))
    y = max(0, min(a[3], b[3]) - max(a[1], b[1]))
    inter = x * y
    area = (a[2]-a[0]) * (a[3]-a[1]) + (b[2]-b[0]) * (b[3]-b[1])
    return inter / (area - inter)

def depth(f, baseline, disparity, disparity_error=1):
    z = f * baseline / disparity
    return z, z*z / (f * baseline) * disparity_error

def metrics(tp, fp, fn):
    iou_score = tp / (tp + fp + fn)
    dice = 2 * tp / (2 * tp + fp + fn)
    return iou_score, dice

print(conv(224, 3, 64, 128, s=2, p=1))  # (112, 73856)
print(ransac(.99, .50, 4))              # 72
print(round(iou((10,10,50,50), (30,20,70,60)), 3))  # .231
print(depth(700, .12, 42))              # (2.0, .048)
print(metrics(80, 10, 20))              # (.727, .842)

Never round down. Use inlier ratio 1 − e, then apply the ceiling. Logs can be any base because this is a ratio.

03 / detection metrics

Intersection over Union

5 marks
Area = (x2 − x1)(y2 − y1)
IoU = Area(A ∩ B) / [Area(A) + Area(B) − Area(A ∩ B)]
Continuous coordinates: do not add +1. Intersection width/height are clamped with max(0, ·).
A = (10, 10, 50, 50), B = (30, 20, 70, 60) → intersection 20 × 30 = 600; IoU = 0.231.

Stereo disparity & depth error

5 marks
d = fB / Z  →  Z = fB / d
ΔZ ≈ (Z² / fB) Δd
Interpretation: depth uncertainty grows with Z². Doubling the distance makes the error about four times larger.

05 / segmentation

Confusion-matrix metrics

5 marks
Pixel accuracy = Σ diagonal / total
IoUc = TP / (TP + FP + FN)
Dicec = 2TP / (2TP + FP + FN) = 2IoU / (1 + IoU)
Convention: rows are ground truth, columns are prediction. For each class, FP comes from the prediction column and FN from the GT row.
TP = 80, FP = 10, FN = 20 → IoU = 0.727; Dice = 0.842.
