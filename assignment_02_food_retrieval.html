What the assignment asks

Turn a sentence into a ranked image search.

You receive a short description such as “Italian pasta parcels with a filling sealed between two layers of thin pasta dough” and a gallery of food images. Return the 20 best image IDs, with the strongest matches first.

Data

2,000 labelled training images, a validation gallery with answers, and a 2,000-image hidden test gallery.

Query variation

Descriptions can use aliases: “potstickers” may refer to gyoza. The wording is not copied exactly from training.

Goal

Retrieve every correct image for the dish near the top of the ranking.

Submission

query_id,image_ids; exactly 20 distinct test image IDs per query.

The winning hybrid method

Use category precision and language understanding together.

①ParseExtract dish name or alias
②ClassifyFine-tuned food CNN
③EmbedCLIP text and image vectors
④FuseBlend both scores
⑤RankReturn top 20 IDs
S(q, x) = 0.6 × P(class = dish | x) + 0.4 × cosine(CLIP_text(q), CLIP_image(x))
Why hybrid? The classifier learns fine-grained boundaries between similar dishes, while CLIP understands synonyms and descriptive language.

Evaluation metrics

Know what the leaderboard rewards.

R-precision = correct images in first R predictions / R
mAP@20 rewards correct images appearing earlier
Precision@5 = correct images in the first 5 / 5
Hit@1 and Hit@5 check whether a correct image appears early
Worked R-precision

If R = 20 and 14 of your first 20 images are correct: 14 / 20 = 0.70.

Important trap

The order inside the first R does not change R-precision, but it does affect mAP@20 and early-hit metrics.

Descriptive answer practice

Try the explanation before revealing the model answer.

Why does a classifier + CLIP ensemble beat either model alone?4 marks
  1. A fine-tuned classifier learns fine-grained visual boundaries between similar food categories.
  2. CLIP understands synonyms and descriptive language even when the exact dish name is missing.
  3. The two scores are complementary: classifier confidence gives category precision, while CLIP similarity gives semantic flexibility.
  4. Score fusion is therefore more robust to both visual similarity and query wording variation.
